FOR NEW LAPTOP - 3 MINUTES SETUP:

1. OPEN POWERSHELL & NAVIGATE TO PROJECT:
   cd 'path\to\blockchain_privacy_platform'

2. CREATE & ACTIVATE VIRTUAL ENVIRONMENT:
   python -m venv p-venv
   .\p-venv\Scripts\Activate.ps1

3. INSTALL DEPENDENCIES:
   pip install --upgrade pip
   pip install django cryptography numpy pandas

4. SETUP DATABASE:
   python manage.py migrate

5. CREATE ADMIN USER:
   python manage.py createsuperuser
   (Enter username, email, password when prompted)

6. START SERVER:
   python manage.py runserver 127.0.0.1:8000

7. OPEN IN BROWSER:
   http://127.0.0.1:8000
   Login with your admin credentials

5 PRIVACY TECHNIQUES:

1. Ring Signature (8/10 security)
   - RSA-PSS 2048-bit keys
   - Hides signer in group
   - Privacy score: ~80.0

2. Zero-Knowledge Proof (10/10 security)
   - Schnorr protocol with EC
   - Prove without revealing
   - Privacy score: ~100.0

3. SMPC (9/10 security)
   - Shamir secret sharing
   - Distributed computation
   - Privacy score: ~89.8-90.0

4. TEE (9/10 security)
   - Hardware isolation (AES-256)
   - Secure enclave simulation
   - Privacy score: ~90.0

5. Mixer (7/10 security)
   - CoinJoin-style mixing
   - Transaction anonymity
   - Privacy score: ~70.0
